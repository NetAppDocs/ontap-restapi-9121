= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Create and manage SVM peering relationships using the SVM peer endpoints. These endpoints enable you to establish connections between SVMs to facilitate data sharing and collaboration across your ONTAP environment.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
