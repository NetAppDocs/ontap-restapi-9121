= Manage NDMP mode
:imagesdir: ./media/

[.lead]
Manage NDMP mode by specifying either SVM-scope or node-scope using the available endpoints. Use these endpoints to update the operational mode as needed for your environment.

You can use this API to manage NDMP mode: SVM-scope or node-scope.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----
