= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configuration settings to manage secure communications within your network. Use these endpoints to check the current IPsec status or update configurations as needed.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
